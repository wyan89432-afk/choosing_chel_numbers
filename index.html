🔢 000 – 999 Number Selector

📘 Search Logic Guide

Search box ထဲမှာ logic တစ်ခုထည့်ပြီး 🔍 Search ကိုနှိပ်ပါ။ စာလုံးအကြီး/အသေး မခွဲပါ။

1. Digit Search
H5 / Hd5 / Top5 → Hundreds = 5 (5xx)
T8 / Td8 / Middle8 → Tens = 8 (x8x)
U3 / Ud3 / Last3 → Units = 3 (xx3)
2. BK Search
BK ဆိုတာ digit 3 လုံးပေါင်းပြီး နောက်ဆုံး digit ကိုယူတာပါ။
ဥပမာ H1 = BK0 → Hundreds = 1 နှင့် digit sum BK = 0
3. Pair Search
H,T,6 → Hundreds + Tens = 6
H,U,5 → Hundreds + Units = 5
T,U,7 → Tens + Units = 7
အပြန်အလှန် T,H / U,H / U,T လည်းရပါတယ်။
4. Pair + BK
H,U,7=BK0 → H+U = 7 နှင့် BK = 0 နှစ်ခုလုံးကိုက်ရမယ်။
Pair sum 10 ကျော်ရင် နောက်ဆုံး digit ကိုသုံးပါတယ်။ ဥပမာ 8+9=17 → 7.
5. Pair + P
H,T,6P3 → H+T = 6 နှင့် number ထဲမှာ digit 3 ပါရမယ်။
6. Pair နှစ်ခု ချိတ်ခြင်း
H,T,4=T,U,6 → တစ်နံပါတ်တည်းမှာ H+T = 4 AND T+U = 6 နှစ်ခုလုံးမှန်ရမယ်။
H,T,4=H,U,6 → H+T = 4 AND H+U = 6.

မှတ်ရန်: H = Hundreds, T = Tens, U = Units. Hd / Td / Ud က shorthand ဖြစ်ပါတယ်။ Condition များစွာရေးထားရင် တစ်နံပါတ်တည်းမှာ အားလုံးကိုက်ညီ ရပါမယ်။
